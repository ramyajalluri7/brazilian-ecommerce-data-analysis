# Brazilian E-Commerce Data Analysis

## Project Overview
Analyzed the Olist Brazilian E-Commerce Public Dataset using Python to identify sales trends, top-performing product categories, delivery delays, and customer satisfaction patterns.

## Tools Used
- Python
- Pandas
- Matplotlib
- Kaggle Notebooks

## Key Findings
- Analyzed 99,441 unique orders.
- Gross item sales totaled R$13.59 million.
- Average customer review score was 4.09/5.
- Late delivery rate was 8.11% among delivered orders with complete delivery dates.
- Health & Beauty led the analyzed categories by gross item sales.
- Late-delivery reviews averaged 2.57/5 versus 4.29/5 for on-time deliveries.

## Business Recommendations
1. Investigate causes of delivery delays.
2. Proactively notify customers about delays.
3. Use category sales trends to guide inventory planning.
4. Investigate low review scores to improve customer experience.

## Dataset
[Olist Brazilian E-Commerce Public Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

## Limitations
Gross item sales are not profit or net revenue. The analysis identifies associations, not proof of causation.
